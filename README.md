# Doushabao

A minimal, responsive product directory built with plain HTML, CSS and JavaScript.

- Magic Grind — https://magicandgrind.com/
- Gray Hole — https://grayhole.tech/
- 塔塔记 — 微信小程序

## Local preview

Serve this directory with any static HTTP server. No dependency installation or build step is required.

## Deployment

GitHub Pages publishes the root directory of the `main` branch. `.nojekyll` keeps the page as a plain static site.

## Assets

Product logos and QR codes belong to their respective owners. The contact QR code is the September 15 copy provided by the existing project; confirm it remains current when replacing contact details.

## Languages

- Simplified Chinese: `/`
- English: `/en/`

Both pages share CSS, scripts, product destinations and contact assets. Update both HTML files when changing product information.
